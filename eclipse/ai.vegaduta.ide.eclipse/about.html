Data sent by this plug-in

When you are signed in and send a message, this plug-in sends the prompt and the code context you chose to attach (the open file, the selection, the uncommitted diff or the file's problems) to the VegaDūta service at api.vegaduta.ai. Nothing is sent until you sign in and send it. Private Mode keeps prompts, code and searches on this machine. The Instant tools run entirely inside the view and send nothing. See https://vegaduta.ai/privacy.
